# PixelPost Mark II

PixelPost Mark II is a preservation, restoration, and continuation project dedicated to the historic Pixelpost photoblogging platform.

This repository is a long-term digital archaeology and cultural preservation initiative, not merely a software fork. Its first responsibility is to recover, document, preserve, restore, and continue the Pixelpost lineage while respecting historical authenticity and provenance.

## Project Phases

- Archaeology
- Preservation
- Restoration
- Continuation

## Core Mission

Recover, document, preserve, restore, and continue the Pixelpost lineage while respecting historical authenticity and provenance.

PixelPost Mark II protects the memory and practice of independent photoblogging: image-first publishing, chronology, personal ownership, editable templates, lightweight deployment, portable archives, and calm publishing rhythms.

## Preservation First

This is not a rewrite-first CMS project. Before modernization, the project must preserve and understand the original Pixelpost ecosystem.

Historical source trees are treated as museum artifacts. Do not reformat, modernize, patch, or normalize them in place.

## Repository Status

The repository is currently private. It should remain private until provenance, preservation doctrine, and restoration boundaries are mature.

Repository structure, documentation, preservation policies, archaeology logs, and provenance templates may be pushed now.

Do not push:

- unverified source archives
- restoration workspace copies
- runtime test artifacts
- materials lacking provenance verification

## Structure

- `archive/original-pixelpost/`: preserved source archives and extracted inspection copies.
- `archive/provenance/`: chain-of-custody records and source verification notes.
- `docs/`: architecture, archaeology, preservation, audit, and restoration documentation.
- `docker/historical/`: future historical runtime definitions.
- `docker/restoration-workspaces/`: disposable first-boot workspaces.
- `runtime-testing/`: runtime test plans, fixtures, and logs.
- `tools/`: preservation and audit helper tools.
