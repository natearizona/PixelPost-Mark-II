# Pixelpost Mark II

Pixelpost Mark II is a digital archaeology, preservation, and historically authentic restoration project for the original Pixelpost photoblogging platform.

This repository is not a rewrite-first CMS project. Its first responsibility is to preserve and understand the original Pixelpost ecosystem before any modernization work begins.

## Project Focus

- Preserve original Pixelpost source material and provenance.
- Reconstruct historical runtime environments.
- Document original architecture, workflows, and assumptions.
- Protect independent photoblog culture and image-first publishing history.
- Prepare for careful restoration and compatibility work later.

## Not This

Pixelpost Mark II is not currently:

- a Laravel, React, or framework migration
- a visual redesign
- a workflow cleanup
- a dependency upgrade project
- a SaaS or social platform
- an AI cleanup pass over historical source

## Repository Status

The repository is intended to remain private until provenance, preservation doctrine, and restoration boundaries are mature.

Recovered archives and extracted historical source trees are treated as museum artifacts. Do not reformat, modernize, patch, or normalize them in place.

## Structure

- `archive/original-pixelpost/`: preserved source archives and extracted inspection copies.
- `archive/provenance/`: chain-of-custody records and source verification notes.
- `docs/`: architecture, archaeology, preservation, audit, and restoration documentation.
- `docker/historical/`: future historical runtime definitions.
- `docker/restoration-workspaces/`: disposable first-boot workspaces.
- `runtime-testing/`: runtime test plans, fixtures, and logs.
- `tools/`: preservation and audit helper tools.
