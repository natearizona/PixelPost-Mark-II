## Evidence Policy

Evidence documents record what Pixelpost did during testing.

Evidence does not record how files moved between machines, which server was used, or what commands were run against infrastructure. Operational records belong in the private infrastructure archive.

See `restoration/evidence/README.md` for the full evidence policy.
