## Required Candidate For Test 1

A valid first historical import candidate should include at minimum:

- SQL dump or MySQL export of a real Pixelpost site.
- Matching `images/` directory.
- `includes/pixelpost.php` or reliable database/table-prefix metadata.

Strong candidates should also include:

- `thumbnails/`
- `templates/`
- `addons/`
- language customizations
- date/source/provenance notes
- historical screenshots or Wayback captures for comparison

## Planned Procedure Once Candidate Exists

When a real historical candidate is available:

1. Copy SQL and filesystem artifacts into a disposable import workspace.
2. Preserve originals read-only.
3. Create a fresh MySQL 5.1.73 database on an internal Docker network.
4. Import the SQL dump.
5. Copy images, thumbnails, templates, addons, and config into a disposable Pixelpost workspace.
6. Reconstruct `includes/pixelpost.php` for the disposable DB credentials if necessary.
7. Run Pixelpost 1.7.3 without source modification.
8. If `pixelpost_version` is older than `1.73`, run the original installer upgrade chain only against the disposable database.
9. Validate public image pages, browse/archive pages, category pages, comments, feeds, EXIF, and admin image inventory.
